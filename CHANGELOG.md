# Changelog

The changelog lives in [`CHANGELOG/`](CHANGELOG/README.md), one file per minor version (for
example [`CHANGELOG-0.3.md`](CHANGELOG/CHANGELOG-0.3.md) holds every `v0.3.x` release, newest
first). It is generated when a release is cut, from the pull requests merged since the previous
tag, so pull requests do not edit it. See [CONTRIBUTING.md](CONTRIBUTING.md#releasing).

This project is pre-1.0, so any release may include breaking changes (see
[README.md#project-status](README.md#project-status)). Entries for `v0.0.1`–`v0.0.9` predate the
changelog; see [GitHub Releases](https://github.com/getsyntegrity/go-specs/releases) for their
auto-generated notes.
